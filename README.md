# Zapret (улучшенная сборка)

Форк проекта [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
с улучшениями для удобства пользователей.

## ✨ Что нового

- **Расширенные списки доменов**: набор популярных сервисов, которые чаще всего
  требуют обхода DPI-фильтрации (мессенджеры, стриминг, соцсети).
- **Автобэкап `hosts`**: перед обновлением файл `hosts` сохраняется
  в `utils/backup/` с датой. Если что-то сломалось — легко откатить.
- **Готовый ярлык на рабочий стол**: запуск в один клик от имени администратора.
- **Архив стратегий**: в корне только рабочая стратегия, остальные — в `utils/archive/`.

## 🚀 Установка

1. Скачайте последний релиз.
2. Распакуйте архив в любую папку (например, `C:\zapret`).
3. Запустите `install_shortcut.bat` — он создаст ярлык «Zapret» на рабочем столе.
4. Кликните по ярлыку «Zapret» — программа запросит права администратора
   и запустит обход.

## 📁 Структура

- `general (ALT11).bat` — рабочая стратегия обхода.
- `service.bat` — менеджер службы (диагностика, обновления, настройки).
- `install_shortcut.bat` — создаёт ярлык «Zapret» на рабочем столе.
- `lists/list-general-user.txt` — ваш список доменов для обхода.
- `utils/archive/` — архив неиспользуемых стратегий.

## ⚠️ Важно

- Zapret **не меняет ваш IP** — он обходит блокировки провайдера (DPI).
- Если сайт показывает "Access Denied" — это геоблокировка
  со стороны сервиса, нужен VPN.
