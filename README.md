# ZapretRKN

Улучшенная сборка [Zapret](https://github.com/bol-van/zapret) на базе
[Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).
Обход DPI-блокировок для массовой аудитории.

## Установка

1. Скачайте архив из [Releases](../../releases).
2. Распакуйте в `C:\ZapretRKN` (важно: путь без кириллицы и пробелов).
3. Запустите `ZapretRKN.exe` — UAC попросит права администратора.
4. Ответьте на вопрос про автозагрузку (по умолчанию — да).
5. Готово. Обход запустится автоматически при следующем входе в систему.

После установки на рабочем столе появится ярлык **ZapretRKN**.
В трее — иконка со статусом и меню управления.

## Управление

Иконка в трее — статус обхода и меню:

- **Остановить / Запустить** — включить или выключить обход без выхода из трея
- **Перезапустить** — перезапуск обхода
- **Стратегия** — выбрать одну из 7 предустановленных стратегий
- **Свой список доменов** — отредактировать `lists\list-general-user.txt`
- **Автозагрузка: ВКЛ / выкл** — включить или отключить автозапуск
- **Ещё**
  - Менеджер службы — открыть `service.bat`
  - Папка ZapretRKN — открыть папку проекта
  - Проверить обновления — фоновая проверка новой версии
  - О программе

Иконка меняет цвет:
- **Красная** — обход работает.
- **Серая** — обход остановлен.

Левый клик — всплывающая подсказка со статусом.
Двойной клик ПКМ — открыть `service.bat`.

### Менеджер службы (`service.bat`)

- `1` — установить службу
- `2` — удалить службы
- `3` — проверить статус
- `4` — Game Filter для Discord
- `5` — режим IPSet (загружен / отключён / любой)
- `8` — обновить IP-лист
- `9` — обновить hosts
- `10` — проверить обновления
- `11` — диагностика с возможностью автопочинки
- `12` — тесты стратегий
- `13` — сменить стратегию
- `14` — обновить движок (winws.exe + .bin)
- `15` — автоподбор лучшей стратегии
- `16` — восстановить движок из бэкапа

## Требования

- Windows 10 / 11 x64
- .NET Framework 4.x (есть в системе по умолчанию)
- Права администратора

## Частые проблемы

**Не работает после установки** — проверьте путь: он не должен содержать русских букв
и пробелов. Перенесите папку в `C:\ZapretRKN` и запустите `ZapretRKN.exe` заново.

**Служба не стартует** — убедитесь, что в `bin\` есть `winws.exe`, `WinDivert64.sys`
и файлы `.bin`. Запустите `service.bat` → пункт `11` (диагностика).

**Discord не работает** — `service.bat` → пункт `4` (Game Filter).

**Антивирус ругается на `ZapretRKN.exe`** — файл не подписан цифровым сертификатом,
это нормально. Добавьте в исключения.


## Для разработчиков

Репозиторий содержит полный набор для сборки:

- `utils/scripts/launcher.cs` — исходник `ZapretRKN.exe`
- `utils/scripts/build_launcher.bat` — сборка `.exe` через `csc.exe`
- `utils/scripts/make_icon.ps1` — генерация `icon.ico` и `icon_grey.ico`
- `utils/scripts/rkn_tray.ps1` — иконка и меню в трее
- `utils/scripts/run_hidden.vbs` — обёртка для скрытого запуска
- `utils/scripts/check_updates.ps1` — фоновая проверка обновлений
- `utils/scripts/check_connectivity.ps1` — проверка доступности сайтов
- `utils/scripts/test_strategies.ps1` — автотест стратегий
- `utils/scripts/update_engine.ps1` — обновление winws.exe и .bin

Пересобрать `ZapretRKN.exe`:

1. Откройте `utils/scripts/build_launcher.bat` двойным кликом.
2. Готовый `.exe` появится в корне проекта.
