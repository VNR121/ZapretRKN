# ZapretRKN

Улучшенная сборка [Zapret](https://github.com/bol-van/zapret) на базе
[Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
с улучшениями для удобства пользователей.

## ✨ Что нового

- **ZapretRKN.exe** — единый лончер: двойной клик запускает установку.
- **Иконка в трее** — статус обхода и меню управления (перезапуск, менеджер
  службы, автозагрузка, выход).
- **Автозагрузка через Task Scheduler** — запуск без UAC-prompt при входе
  в систему.
- **Тёмное меню трея** — минималистичный интерфейс.
- **Ярлык ZapretRKN на рабочем столе** — с иконкой проекта и автозапуском
  от администратора.
- **Расширенные списки доменов** — мессенджеры, стриминг, соцсети.
- **Автобэкап `hosts`** — перед обновлением файл `hosts` сохраняется
  в `utils/backup/` с датой. Если что-то сломалось — легко откатить.

## 🚀 Установка

1. Скачайте последний релиз.
2. Распакуйте архив в `C:\ZapretRKN` (путь без кириллицы — иначе
   `winws.exe` не читает `.bin`-файлы).
3. Запустите `ZapretRKN.exe`.
4. Разрешите UAC.
5. Ответьте на вопрос про автозагрузку (по умолчанию — да).
6. Готово. Обход запустится автоматически при следующем входе в систему.

После установки на рабочем столе появится ярлык **ZapretRKN**.
В трее — иконка со статусом и меню управления.

## 📁 Структура

- `ZapretRKN.exe` — лончер установки.
- `general (ALT11).bat` — рабочая стратегия обхода.
- `service.bat` — менеджер службы (двойной клик по иконке в трее):
  - `2` — удалить службу
  - `3` — проверить статус
  - `4` — Game Filter для Discord
  - `8` — обновить IP-список
  - `11` — диагностика
  - `12` — тесты стратегий
- `install.bat` — скрипт установки (вызывается из `ZapretRKN.exe`).
- `lists/list-general-user.txt` — ваш список доменов для обхода.
- `utils/scripts/rkn_tray.ps1` — иконка в трее.

## ⚠️ Важно

- Zapret **не меняет ваш IP** — он обходит блокировки провайдера (DPI).
- Если сайт показывает "Access Denied" — это геоблокировка
  со стороны сервиса, нужен VPN.
- Если обход не работает — проверьте, что путь к папке не содержит
  русских букв. Перенесите проект в `C:\ZapretRKN` и запустите
  `ZapretRKN.exe` заново.
- Антивирус может ругаться на `ZapretRKN.exe` — файл не подписан
  цифровым сертификатом. Добавьте его в исключения.
